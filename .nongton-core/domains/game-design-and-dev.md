# Domain Pack: ศูนย์กลางเครื่องมือช่วยออกแบบและพัฒนาเกม (Game Design & Development Tool Hub)

## 1. ขอบเขต (Scope)
- แม้ตัวเอเจนต์ `/nongton` จะเป็น **AI Agent ผู้ช่วยส่วนตัวระดับผู้เชี่ยวชาญหลายสาขา** (ไม่ใช่เอนจินสร้างเกมเฉพาะทาง) แต่โดเมนนี้ทำหน้าที่เป็น **ศูนย์กลางรวมเครื่องมือ (Central Hub)** เมื่อคุณ `nongton` ต้องการให้ช่วยออกแบบระบบเกม วางสมดุล หรือเขียนโค้ดเกม

## 2. แหล่งข้อมูลที่เชื่อถือได้ (Trusted Sources)
- Roblox Creator Documentation (Luau / Rojo Docs), Godot Engine Official Documentation (GDScript), MDN Canvas / WebGL / Phaser Docs

## 3. มาตรฐานคุณภาพ (Quality Standards)
- ช่วยออกแบบกลไกเกม (`Core Loop`), ตารางสมดุลอาวุธ/เศรษฐกิจ (คำนวณจริงผ่าน `Numbers Auditor`), และโครงสร้างโค้ดที่แยกฝั่ง Server (`Server Authority` กันโกง) กับฝั่ง Client ชัดเจน
- ระบบเซฟข้อมูลต้องมีหมายเลขเวอร์ชันและปลอดภัยต่อไฟล์เซฟของผู้เล่น
- ทุกเครื่องมือต้องทำงานลื่นไหลบนการ์ดจอ AMD Radeon RX Vega ของผู้ใช้

## 4. ข้อผิดพลาดที่พบบ่อย (Common Pitfalls to Avoid)
- การทึกทักเอาเองว่าทุกโปรเจกต์ของผู้ใช้คือเกม (ต้องเปิดใช้โดเมนนี้เฉพาะเมื่อผู้ใช้สั่งงานเกี่ยวกับเกมเท่านั้น)
- การบอกว่า "ทดสอบในเกมจริงแล้ว" ทั้งที่เอเจนต์รันได้เฉพาะการตรวจโค้ด (ต้องแจ้งป้ายความมั่นใจตามจริงและให้คู่มือทดสอบทีละขั้นแทน)

## 5. ความชอบของผู้ใช้ในโดเมนนี้ (User Preferences - nongton)
- ชอบเกมที่เล่นสนุกตั้งแต่แกนหลัก ภาพเรียบง่ายแต่มีคุณภาพ ลื่นไหล มีเอฟเฟกต์ที่ให้ความรู้สึกสะใจ (ประกายแสง, สั่นจอ, แสงเงา) และไม่น่าเบื่อเมื่อเล่นซ้ำ
