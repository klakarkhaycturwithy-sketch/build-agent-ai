# Domain Pack: พัฒนาเว็บและซอฟต์แวร์ (Web & Software Development)

## 1. ขอบเขต (Scope)
- การเขียนและแก้ไขโค้ด `HTML`, `CSS`, `JavaScript`, `Python`, `Node.js`, `Vite` การดีบัก การออกแบบสถาปัตยกรรมระบบ และการนำขึ้น GitHub / Vercel / Netlify

## 2. แหล่งข้อมูลที่เชื่อถือได้ (Trusted Sources)
- MDN Web Docs, Python Official Documentation, Node.js Docs, Vite Docs, GitHub Official Docs, Vercel Docs

## 3. มาตรฐานคุณภาพ (Quality Standards)
- ยึดหลัก Clean Code (ฟังก์ชันสั้น อ่านเข้าใจง่าย แยกหน้าที่ชัดเจน ไม่ซับซ้อนเกินจำเป็น)
- รองรับฮาร์ดแวร์ของผู้ใช้ (Windows, AMD Ryzen 5 5600, RAM 32 GB, GPU AMD Radeon RX Vega — ห้ามแนะนำเครื่องมือที่ผูกติดกับ CUDA/NVIDIA)
- ต้องทดสอบรันจริงและตรวจว่าไม่มี Error ใน Console ก่อนส่งมอบ

## 4. ข้อผิดพลาดที่พบบ่อย (Common Pitfalls to Avoid)
- การแก้โค้ดส่วนที่ทำงานได้ดีอยู่แล้วโดยไม่ถามก่อน หรือไม่สำรองไฟล์ลง `.backups/`
- การฝัง API Key หรือข้อมูลลับลงในโค้ดโดยตรง (ต้องใช้ `.env` เสมอ)

## 5. ความชอบของผู้ใช้ในโดเมนนี้ (User Preferences - nongton)
- โค้ดและคอมเมนต์เป็นภาษาอังกฤษ คำอธิบายเป็นภาษาไทยเข้าใจง่าย อธิบายศัพท์เทคนิคในวงเล็บพร้อมเปรียบเทียบให้เห็นภาพ

## 6. การเชื่อมโยงสู่ Web Design & Development Specialist Pack
- สำหรับงานออกแบบและพัฒนาเว็บไซต์หรือเว็บแอปขนาดใหญ่ (Multi-page, E-commerce, Dashboard, Design System, Thai/EN Bilingual Sites) ให้เปิดอ่านและใช้คู่มือเฉพาะทางหลักที่ `.nongton-core/domains/web-design-development.md` ควบคู่กับไฟล์นี้ (ไฟล์นี้ยังคงครอบคลุมงานสคริปต์ Python, Node.js, CLI, และการดีบักซอฟต์แวร์ทั่วไป)
