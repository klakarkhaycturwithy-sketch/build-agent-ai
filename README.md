# nongton — Multifaceted Personal Assistant AI Agent (v1.3)

**`nongton`** คือ **ผู้ช่วยส่วนตัวอัจฉริยะรอบด้าน (Multifaceted Personal Assistant AI Agent)** ที่มีความเชี่ยวชาญเชิงลึกในหลากหลายสาขา พร้อม **ทีมงาน 6 บทบาทในตัว** ที่ทำหน้าที่ **ค้นคว้าวิจัยอย่างละเอียด (Thorough Research)**, **ตรวจสอบความถูกต้องของข้อมูล (Information Verification & Fact-Checking)**, ออกแบบ, พัฒนา และควบคุมคุณภาพ (`หัวหน้า > รองหัวหน้า/ค้นคว้าวิจัย > Design/โครงสร้าง > Backend/วิเคราะห์และตรรกะ > Frontend/การนำเสนอ > QA/ตรวจสอบความถูกต้อง`) เพื่อให้งานและโปรเจกต์ทุกชิ้นของคุณ **nongton** ออกมามีคุณภาพสูงสุด

---

## 3. โครงสร้างคลังความเชี่ยวชาญใน `.agents/skills/nongton/`

- **`SKILL.md`** — ทางเข้าคำสั่งเดียว (`/nongton`) และสมองคัดแยกสายงานอัตโนมัติ (Auto-Intent Router)
- **`references/research-verification.md`** — มาตรฐานการค้นคว้าวิจัยเชิงลึก (Deep Research) และการตรวจสอบความถูกต้องของข้อมูล (Fact-Checking)
- **`references/web-studio.md`** — มาตรฐานการออกแบบและพัฒนาเว็บ/ระบบ (Minimal Light 2 ภาษา TH/EN)
- **`references/code-coach-unblock.md`** — โหมดสอนหลักคิดสำหรับมือใหม่ (Teaching Mode) และปลดล็อกเมื่อตัน (Unblock Mode)
- **`references/deploy-security.md`** — การตรวจความปลอดภัย ลิขสิทธิ์ (`COPY GATE`) และการส่งมอบงานขึ้น GitHub/Vercel
- **`references/session-manager.md`** — การจัดการความจำ (`PROJECT_MEMORY.md`), เซสชัน และระบบสำรองไฟล์ (`.backups/`)
- **`references/game-studio-v1.2.md`** — โมดูลเสริมเฉพาะทางเมื่อได้รับโจทย์ด้านอินเทอร์แอคทีฟหรือเอนจิน (Roblox Luau+Rojo / Godot GDScript)
