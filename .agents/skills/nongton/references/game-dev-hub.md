# ศูนย์กลางเครื่องมือช่วยออกแบบและพัฒนาเกม (Game Design & Development Tool Hub)

โมดูลความเชี่ยวชาญเฉพาะทางภายใต้ **Personal Assistant AI Agent (`/nongton`)**
- แม้ `/nongton` จะเป็น **AI Agent ผู้ช่วยส่วนตัวระดับผู้เชี่ยวชาญหลายสาขา** (ไม่ใช่เอนจินสร้างเกมเฉพาะทาง) แต่โมดูลนี้ทำหน้าที่เป็น **ศูนย์กลางรวมเครื่องมือ (Central Hub)** เมื่อคุณ `nongton` ต้องการให้ช่วยออกแบบหรือพัฒนาเกม

## เครื่องมือและความเชี่ยวชาญในศูนย์กลางนี้
1. **การออกแบบระบบและสมดุลเกม (Game Design & Balancing):**
   - ช่วยคิด Core Loop, ออกแบบตารางสมดุลอาวุธ/เศรษฐกิจ/เลเวล (แยกข้อมูลเป็นตารางปรับง่าย), และวางโครงเอกสาร GDD ฉบับกระชับ
   - ใช้ `Numbers Auditor` คำนวณสมดุลตัวเลข (เช่น DPS, อัตราการดรอป, ความเร็วการเติบโตของราคา) ด้วยโค้ดจริง
2. **การช่วยเขียนโค้ดและเชื่อมต่อเอนจิน (Multi-Engine Coding Assistance):**
   - **Roblox Studio (ภาษา Luau + Rojo):** ช่วยออกแบบโครงสร้าง `ServerScriptService` (`Server Authority` ป้องกันการโกง), `ReplicatedStorage`, `StarterPlayerScripts`, และระบบเซฟ `DataStoreService` ที่ปลอดภัย
   - **Godot Engine (ภาษา GDScript):** ช่วยออกแบบ Scene Tree, Signal, ระบบฟิสิกส์/การเคลื่อนที่, และระบบเซฟไฟล์ที่เข้ากันได้กับการ์ดจอ AMD Radeon RX Vega
   - **Web Games (HTML5 Canvas / Phaser / Three.js):** ช่วยสร้างต้นแบบเกมบนเว็บที่เปิดเล่นและแชร์ผ่าน Vercel ได้ทันที
3. **การตรวจสอบลิขสิทธิ์และกฎแพลตฟอร์ม:**
   - ตรวจสอบไลเซนส์ของแอสเซ็ตภายนอก บันทึกแหล่งที่มาใน `SOURCES.md` และตรวจกฎของแพลตฟอร์มปลายทางก่อนเผยแพร่
