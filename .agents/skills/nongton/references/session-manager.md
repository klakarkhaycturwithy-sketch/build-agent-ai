# Session & Prompt Manager Reference (Memory, Backup & Rules Sync)

คู่มือจัดการเซสชัน ความจำ (`PROJECT_MEMORY.md`) และการอัปเดตระบบ Prompt ที่ถูกเรียกใช้อัตโนมัติผ่านคำสั่ง `/nongton`

## 1. การเริ่มต้นเซสชัน (`เริ่มเซสชัน` หรือเปิดงานต่อเนื่อง)
1. อ่านไฟล์ความจำและเอกสารโปรเจกต์ทั้งหมดที่มีอยู่ในโฟลเดอร์:
   - `PROJECT_MEMORY.md` (ความจำหลักและข้อมูลความชอบของคุณ `nongton`)
   - เอกสารโปรเจกต์เกม (ถ้ามี): `DECISIONS.md`, `GDD.md`, `BACKLOG.md`, `CHANGELOG.md`, `ASSETS.md`, `TESTLOG.md`
2. สรุปสถานะปัจจุบันสั้นๆ **3 บรรทัด** ก่อนเริ่มงาน:
   - **ทำถึงไหนแล้ว:** สรุปงานล่าสุดที่เสร็จไป
   - **ติดอะไรอยู่:** ปัญหาหรือการตัดสินใจที่ค้างอยู่ (ถ้าไม่มีให้ระบุว่าไม่มี)
   - **ขั้นต่อไป:** แนะนำก้าวต่อไปที่ทำต่อได้ทันที

## 2. การแก้ไข Prompt หรือกฎของระบบ (`AGENTS.md`, `.agents/`)
1. **สำรองไฟล์ก่อนเสมอ (`HARD RULE 2`):** คัดลอกไฟล์ที่จะแก้ไปไว้ใน `.backups/YYYYMMDD-HHMM/` ก่อนลงมือแก้ทุกครั้ง
2. **ห้ามลบไฟล์ (`HARD RULE 1`):** หากต้องการเอาไฟล์ออก ให้ย้ายไปไว้ใน `_to_delete/` แทนการลบจริง
3. **รักษาเพดานขนาดไฟล์กฎ (`< 24,000 bytes`):** ตรวจสอบขนาดไฟล์ `.md` ทุกไฟล์ใน `AGENTS.md` และ `.agents/rules/` ไม่ให้เกิน 24,000 bytes เพื่อให้ Antigravity โหลดกฎครบ 100%
4. **ซิงก์ข้ามแพลตฟอร์ม:** เมื่ออัปเดตต้นน้ำที่ `Build Agent Ai` เสร็จ ให้รัน `npx nongton` เพื่อซิงก์และเช็กสถานะ `READY` ครบทุกรายการ
